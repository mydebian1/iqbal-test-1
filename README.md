# Cabline Driver Onboarding

Nuxt 3 driver-facing onboarding portal for Cabline recruitment.

This app is currently themed to match `cabline-drivers-frontend` and is ready for the next phase: connecting invite lookup, driver login, document upload, and onboarding status APIs.

## Stack

- Nuxt 3
- Vue 3
- PrimeVue 4
- Tailwind CSS 3
- Cabline PrimeVue theme tokens

## Commands

```bash
npm install
npm run dev
npm run build
```

## Theme

The Cabline theme lives in:

- `theme/index.js`
- `assets/css/main.css`
- `tailwind.config.js`

The theme mirrors the drivers frontend primary color, flat controls, bordered panels, neutral backgrounds, and compact typography.
